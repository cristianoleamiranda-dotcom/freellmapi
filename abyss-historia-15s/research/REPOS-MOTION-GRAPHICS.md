## Qué elegiría para cada caso

| Objetivo | Herramienta | Por qué |
|---|---|---|
| Sitio de Sender con scroll inmersivo | GSAP + Lenis + Three.js | Es lo que ya tienes montado y lo que pide el brief |
| UI de producto (freellmapi, dashboards) | Motion (React) | Curvas y springs sin pelear con el DOM |
| Variantes de la historia de Abyss (4:5, 1:1, 16:9) | Remotion o mi pipeline | Remotion si quieres preview; Python si quieres render headless |
| Animación de iconos y logo en app | Rive o Lottie | Pesa poco y se controla por estado |
| Explicativos técnicos | Motion Canvas | Timeline como código, buen tipado |
| Gráficos de datos animados | Manim o D3 + GSAP | Precisión y control de ejes |

## Cómo se comprobó

```bash
gh api repos/motiondivision/motion -q '.stargazers_count, .license.spdx_id, .pushed_at'
```

Las licencias «propias» (GSAP, Remotion) tienen condiciones específicas: revísalas antes
de un uso comercial en cliente. GPL y LGPL (Blender, Natron, FFmpeg, glaxnimate) imponen
condiciones si redistribuyes el software.
«Sin licencia» significa **todos los derechos reservados**: no se puede reutilizar sin
permiso, aunque el código esté público.
