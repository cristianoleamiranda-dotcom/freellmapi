# SKILL · Design System "Broadcast Editorial"
1. Definir tokens ANTES de escribir componentes (03-REFERENCIA).
2. Ritmo de actos: alternar papel/oscuro para jerarquizar; el pico (catálogo) siempre oscuro con film-language.
3. Hairlines en vez de sombras para estructura; sombra profunda solo en media (stacks/slides).
4. Mono uppercase ls≥.2em para todo metadato; display solo para títulos; serif solo para citas.
5. Paleta oficial innegociable; derivados solo con alpha o tintes documentados (--ice).
6. Cada sección declara su número (data-wm) → outline gigante como marca editorial.
